# Valleys Symphony Orchestra — премиальный многостраничный сайт

**Статус:** готовый статический демонстрационный сайт с 23 HTML-страницами, адаптивной вёрсткой, интерактивной рассадкой, фильтром афиши, галереей и локальной формой обращения.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. В меню доступны все основные страницы.

Для надёжного тестирования через локальный HTTP-сервер (рекомендуется) при установленном Python откройте терминал в папке сайта и запустите:

```bash
python -m http.server 8000
```

Адрес: `http://localhost:8000/`.

Для публикации на **GitHub Pages**, Netlify или любом обычном веб-хостинге достаточно разместить содержимое папки в корне сайта. Сборка и Node.js не требуются.

## Использованные изображения

Ровно **15 ранее сгенерированных изображений без нанесённого текста**:

- `orchestra.webp` — широкий портрет оркестра 20:9
- `conductor.webp` — дирижёр 9:16
- `first-violins.webp`, `second-violins.webp`, `violin-solo.webp`, `violins.webp`, `cellos.webp`, `basses.webp`, `woodwinds.webp`, `percussion.webp` — 8 фотографий струнных и инструментальных групп плюс индивидуальная карточка
- `about.webp`, `press.webp`, `photos.webp`, `videos.webp`, `concerts.webp` — 5 коллажей 16:9 для разделов

Все изображения автоматически сохранены в WebP. Их общий размер составляет приблизительно **3,8 МБ**. Карта соответствия исходников: `assets/image-manifest.json`.

**Афиши с надписями, ранее сгенерированные в диалоге, не использованы.** Вместо них реализованы редактируемые HTML/CSS-постеры, собранные поверх наших безтекстовых коллажей.

## Редактирование

- Основные тексты, структура страниц и демонстрационные концерты — `tools/build_site.py`.
- Цвета, типографика и адаптивность — `assets/css/site.css`.
- Интерактивная карта, фильтры, галерея, меню — `assets/js/site.js`.
- Изображения — `assets/images/*.webp`.

Чтобы изменить содержимое страниц массово, отредактируйте `tools/build_site.py` и выполните:

```bash
python tools/build_site.py
```

Для работы генератора нужен Python с Pillow (`pip install pillow`). Генератор может пересобрать страницы по уже оптимизированным изображениям. Чтобы заменить иллюстрации исходниками, создайте папку `source_images/` в корне проекта и используйте имена из `assets/image-manifest.json`. Файлы повторно конвертируются в WebP.

**Обратите внимание:** группы инструментов представлены в двух местах: в массиве `sections` генератора и в массиве `sections` JavaScript для интерактивной схемы. При переименовании или добавлении групп обновите оба места.

## Что пока демонстрационное

- Валидные, но **не настоящие** персональные сведения и показатели.
- Даты, площадки, солисты, контактные адреса ещё не назначены.
- Билетная система, публикации, альбомы и видео не подключены.
- Контактная форма **не отправляет** писем; она только формирует текст обращения и копирует его при разрешении браузера.
- Логотип Valleys Cultural Group выполнен как типографическая заглушка, так как исходный «вариант 4» не передан отдельным файлом.
- Схема рассадки иллюстративна и не претендует на точную посадку реального коллектива.

Поэтому в проекте нет имитации успешной продажи билетов или отправки заявок, вымышленных отзывов реальных СМИ, фиктивных партнёрств и несуществующих записей.

## Технологии

Этот архив — **независимая статическая реализация на HTML5, CSS3 и JavaScript без внешних зависимостей**, созданная для немедленного открытия и размещения на статическом хостинге. Это не Next.js-проект и не требует `npm install`. Визуальные анимации реализованы CSS и IntersectionObserver; GSAP не используется.

Используются Google Fonts (Cormorant Garamond и Manrope). При отсутствии подключения к интернету срабатывают резервные системные шрифты.

## Проверки

- 23 сгенерированные страницы.
- Все относительные HTML-ссылки и локальные медиа-пути проверены автоматически: отсутствующих файлов нет.
- JavaScript прошёл проверку синтаксиса Node.js.
- CSS прошёл базовый синтаксический разбор.
- Удалены градиенты, тени и неоновые эффекты.
- Полноценные браузерные скриншоты и Lighthouse в текущем окружении получить не удалось из-за ограничений запуска страниц в Chromium. Адаптивную вёрстку на реальных устройствах следует проверить перед публичным запуском.
